# DSS ท่าเรือ — ระบบสนับสนุนการตัดสินใจจัดลำดับความสำคัญการลงทุนท่าเรือ

Project 2 · T1-2569-273453 Decision Support Systems (Sec1)

ระบบสนับสนุนการตัดสินใจจัดลำดับความสำคัญการลงทุนท่าเรือ ตามปริมาณสินค้านำเข้า-ส่งออก ผู้ใช้นำเข้าข้อมูลการค้า (CSV) → ดูแนวโน้ม → ปรับน้ำหนักเกณฑ์ → ระบบคำนวณคะแนน Weighted Scoring (V/G/D/B/S) จัดอันดับ และจัดชั้นตามตารางกฎการตัดสินใจ 4 ข้อ → ดูผล/ส่งออกรายงาน

## วิธีรัน (ไม่ต้องติดตั้งอะไรเพิ่ม)

ใช้ **Node.js core เท่านั้น ไม่มี dependency ภายนอก** (ไม่ต้อง `npm install`) ฐานข้อมูลใช้ SQLite ที่มากับ Node.js (`node:sqlite`)

ต้องมี [Node.js](https://nodejs.org) **เวอร์ชัน 22.13 ขึ้นไป** (เช็คด้วย `node -v`)

```bash
node server/index.js      # หรือ npm start
```

เปิดเบราว์เซอร์ไปที่ **http://localhost:3000** (ต้องเปิดผ่านเซิร์ฟเวอร์ ดับเบิลคลิก index.html ไม่ได้) · หยุดด้วย `Ctrl+C`

ครั้งแรกที่รัน ระบบสร้างฐานข้อมูล `server/data/dss.db` แบบ**ว่างเปล่า** และเปิดหน้า "นำเข้าข้อมูล" ให้ก่อน ข้อมูลที่นำเข้าแล้วเก็บถาวร ปิด/เปิดเซิร์ฟเวอร์ใหม่ข้อมูลยังอยู่

## ขั้นตอนสาธิต

1. หน้า "นำเข้าข้อมูล" กด **ล้างข้อมูลทั้งหมด** (ถ้ามีข้อมูลค้างจากการซ้อม) → ทุกหน้าว่าง
2. เลือกไฟล์ `demo-data/ปริมาณการขนส่งสินค้าระหว่างประเทศ.csv` (ชีต "ข้อมูลต้นฉบับ+หมวดหมู่" ที่ Excel บันทึกเป็น CSV, 956 แถว) → กด **นำเข้าและคำนวณใหม่**
3. ไล่ดูหน้า 2 → 5 · ลองเปลี่ยนโปรไฟล์น้ำหนักในหน้า 3 แล้วดูอันดับในหน้า 4–5 เปลี่ยนตาม · ส่งออก CSV / PDF ในหน้า 4

ถ้าจะใช้ไฟล์ Excel อื่น: เปิดชีตข้อมูลดิบ → File › Save As › **CSV UTF-8 (Comma delimited)** (แบบ "CSV (Comma delimited)" ธรรมดาก็ได้ ระบบอ่านภาษาไทยได้ทั้งสองแบบ) — ใช้ไฟล์ Excel ต้นฉบับได้เลย ระบบรู้จักหัวคอลัมน์ ปี พ.ศ., จังหวัด, ประเภท (ขาเข้า/ขาออก), สินค้าเดิม, หมวดหมู่ใหม่, น้ำหนักรวม

## รูปแบบไฟล์ที่นำเข้าได้ (CSV)

ระบบตรวจรูปแบบจากหัวคอลัมน์ให้เอง การนำเข้าจะ **แทนที่ข้อมูลเดิมทั้งชุด** (ถ้าต้องการเก็บปีเก่า ให้รวมไว้ในไฟล์เดียวกัน) ถ้าไฟล์มีข้อผิดพลาด ระบบบอกเลขแถวที่ผิดและไม่แตะข้อมูลเดิม

V,G,D,B,S คือ**ค่าตัวชี้วัดที่คำนวณจากข้อมูล** (เช่น อัตราการเติบโต, ดัชนีเสถียร) ไม่ใช่คะแนนสำเร็จรูป ถ้าไฟล์มีมาแล้ว ระบบแค่ไม่ต้องคำนวณตัวนั้นเอง ขั้นตอนหลังจากนั้นเหมือนกันเสมอ: ปรับสเกล 0–100 (min-max) → ถ่วงน้ำหนัก → จัดอันดับ → จัดชั้น

1. **ข้อมูลดิบ**: `Year_BE, ProvinceName_TH, ProcessingIndicator (นำเข้า/ส่งออก), CategoryName_TH, TotalWeight (ตัน)` (ไม่บังคับ: `ProvinceName_EN, CategoryName_EN, OriginalGoodsMapping`) — ตัวอย่าง `public/samples/port-trade-2565-2568.csv`
   - **ใส่คอลัมน์ V, G, D, B, S เพิ่มได้ (บางตัวหรือครบ)** → ใช้ค่าจากไฟล์แทนตัวนั้น ตัวที่ไม่มีคำนวณเอง ค่าเป็นระดับจังหวัด ใส่แถวไหนของจังหวัดนั้นก็ได้ แต่ต้องครบทุกจังหวัดและตรงกันทุกแถว
   - ถ้าต้องคำนวณ G หรือ S เอง ต้องมีข้อมูลอย่างน้อย 2 ปี
2. **มีแต่ค่าตัวชี้วัด (ไม่มีข้อมูลดิบ)**: `ProvinceName_TH, V, G, D, B, S, AvgVolumeTon` 1 แถว = 1 จังหวัด ต้องครบ 5 ตัว สเกลใดก็ได้ (ไม่บังคับ: `Year_BE, ProvinceName_EN`) — ตัวอย่าง `public/samples/template-indicators.csv` · ไม่มีข้อมูลรายปี จึงไม่มีกราฟแนวโน้ม

รองรับหัวคอลัมน์ภาษาไทย (ปี, จังหวัด, นำเข้า/ส่งออก, หมวดสินค้า, น้ำหนัก) ปี พ.ศ./ค.ศ. และไฟล์ที่ Excel บันทึกเป็น UTF-8 หรือ ANSI ภาษาไทย (windows-874)

## สถาปัตยกรรม 3 ชั้นของ DSS

1. **Data Management** — `server/lib/db.js` + `importer.js`: SQLite 4 ตาราง `PROVINCE`, `GOODS_CATEGORY`, `TRADE_RECORD`, `PRIORITY_SCORE` (PK/FK ตาม ER) นำเข้าข้อมูลจาก CSV แบบ transaction (พังกลางทาง = rollback ข้อมูลเดิมไม่หาย)
2. **Model/Analytics** — `server/lib/calc.js`: V (log ปริมาณเฉลี่ย), G (YoY growth เฉลี่ย), D (1−HHI ของ 7 หมวด), B (ความสมดุลนำเข้า-ส่งออก), S (1/(1+CV)) → min-max 0-100 → Weighted Scoring → ตารางกฎ 4 ข้อ
3. **UI & Visualization** — `public/`: 5 หน้าจอตาม Use Case

## API (รายละเอียดใน `API_CONTRACT.md`)

- `GET /api/dashboard-data` — ข้อมูลชุดปัจจุบัน แนวโน้ม และอันดับฐาน
- `POST /api/recalculate` — `{ weights: {V,G,D,B,S}, volumeThresholdTon? }` → อันดับใหม่ + `baseRank`
- `POST /api/import` — `{ fileName, csv }` → นำเข้าแทนที่ข้อมูลเดิมและคำนวณใหม่
- `POST /api/reset-sample` — โหลดชุดข้อมูลตัวอย่าง
- `POST /api/clear` — ล้างข้อมูลทั้งหมด
- `GET /api/health`
