# DSS ท่าเรือ — ระบบสนับสนุนการตัดสินใจจัดลำดับความสำคัญการลงทุนท่าเรือ

Project 2 · T1-2569-273453 Decision Support Systems (Sec1)

ระบบสนับสนุนการตัดสินใจจัดลำดับความสำคัญการลงทุนท่าเรือ ตามปริมาณสินค้านำเข้า-ส่งออก ครอบคลุม 23 พื้นที่ท่าเรือ คำนวณคะแนนด้วยวิธี Weighted Scoring (V/G/D/B/S) และจัดชั้นความสำคัญตามตารางกฎการตัดสินใจ 4 ข้อ

## วิธีรัน (ไม่ต้องติดตั้งอะไรเพิ่ม)

ระบบนี้เขียนด้วย **Node.js core เท่านั้น ไม่มี dependency ภายนอกเลย** (ไม่ใช้ Express/npm package ใด ๆ) จึงรันได้ทันทีโดยไม่ต้องเชื่อมอินเทอร์เน็ตหรือรอ `npm install` — เหมาะสำหรับวันสาธิตสดที่อาจไม่มีเน็ตในห้องเรียน

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไปติดตั้งอยู่ในเครื่อง (เช็คด้วย `node -v`)

```bash
# 1) เปิด terminal ในโฟลเดอร์โปรเจกต์นี้
cd dss-project2

# 2) รันเซิร์ฟเวอร์
node server/index.js
# หรือ
npm start
```

จากนั้นเปิดเบราว์เซอร์ไปที่ **http://localhost:3000**

หยุดเซิร์ฟเวอร์ด้วย `Ctrl+C`

## สถาปัตยกรรม 3 ชั้นของ DSS (ตามที่โจทย์กำหนด)

1. **Data Management Layer** — `server/data/*.json` ข้อมูลดิบจาก Excel จริง (23 พื้นที่ ไม่กรองออกพื้นที่ใด รวมเขตเศรษฐกิจจำเพาะ), โหลดเข้าหน่วยความจำตอนสตาร์ทเซิร์ฟเวอร์
2. **Model/Analytics Layer** — `server/lib/calc.js` คำนวณ V,G,D,B,S จากข้อมูลดิบเองทั้งหมด (ไม่ใช้ค่าที่คำนวณสำเร็จรูปมาจาก Excel) ด้วยสูตร log-scale (V), YoY growth (G), 1-HHI (D), balance ratio (B), 1/(1+CV) (S) แล้ว min-max normalize เป็น 0-100 จากนั้นจัดชั้นด้วยตารางกฎ 4 ข้อ
3. **UI & Visualization Layer** — `public/` 4 หน้าจอ: ภาพรวม (FR1,FR2) · จัดลำดับความสำคัญ (FR4,FR5) · จำลองสถานการณ์ What-if (FR3) · คะแนนตัวชี้วัดรายพื้นที่ (FR6)

## API

ดูรายละเอียดเต็มใน `API_CONTRACT.md`

- `GET /api/dashboard-data` — ข้อมูลทั้งหมดสำหรับหน้าเว็บ (น้ำหนักเริ่มต้น: สมดุล V40/G25/D15/B10/S10)
- `POST /api/recalculate` — ส่ง `{ "weights": {V,G,D,B,S} }` (รวมกันต้องได้ 1.0) กลับมาเป็นอันดับใหม่พร้อม `baseRank` เทียบของเดิม
- `GET /api/health` — เช็คว่าเซิร์ฟเวอร์พร้อมใช้งาน

## ก่อนสาธิต / นำเสนอ
